choose useful complete-well corrections. Run 10 then established that A960 is
systematically under-actuated: a held-excluded scalar calibration gained
`0.144807308`, and a trainable one-amplitude-per-well model gained
`0.159136997` after A960. The latter is the retained parent.

The registered Run-10 ridge over scalar and wellwise calibration failed at
`5.520302437`. Those outputs are alternative amplitudes of almost the same
direction, so a linear stack dilutes rather than diversifies the better path.

A legal development diagnostic over immutable, selection-clean archives found
four directions that are materially less correlated:

- local residual seed bag;
- multiscale residual bag;

- protected categorical mode bank.

Adding each direction conservatively to the Run-10 parent improves all four
open roles at some fixed positive share. A bounded four-direction diagnostic
reaches approximately `5.449` with same-data weights, while a fixed-identity
other-three-role diagnostic reaches approximately `5.463`. These are
headroom diagnostics, not promotable scores or deployable weights.

## Missing feature mechanism

Run 10's 206 amplitude features summarize predictions and GR likelihoods, but
they omit direct legal query context: absolute and relative trajectory
geometry, horizontal-GR acquisition statistics, visible-prefix geometry,
typewell-profile shape, and typewell-family identity. This is a plausible
reason its F0 amplitude is too conservative while F1--F3 are well calibrated.
The public complete-well clues likewise emphasize full trajectory tangents,
typewell GR shape, and complete-horizon context.

Run 12 therefore tests three prospectively frozen mechanisms:

1. replace the Run-10 amplitude model with a structure-aware amplitude model
   trained from the same A960 analytic target but augmented only with legal
   complete-well query features;
2. predict a small anchor-zero low-frequency residual after the retained
   Run-10 parent from those same legal features;
3. if needed, combine the four independently frozen clean residual directions
   with a held-excluded bounded ridge.

Every learned normalization, target clip, model parameter, candidate weight,
and recipe choice applied to held role `h` is fit or selected only from the
other three roles. Each family has an exact no-op. A metric-free feature and
selector gate must pass before its one selection-clean F0--F3 evaluation.
