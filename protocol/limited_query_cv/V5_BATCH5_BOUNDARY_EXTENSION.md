# V5 Batch 5 boundary extension

Batch 5 adds one research batch and one protected reveal. It replaces the
spent original grouping with a target-free, cluster-balanced whole-well
grouping frozen in `v5_batch5_target_free_boundary.json`.

All wells sharing an exact-overlap typewell cluster remain in one fold. F0-F3
are available for Batch 5 development; the new F4 stays sealed until a global
pipeline and its 10 pair plus five outer roles are frozen. The active parent
remains `run4_structural_surface_router_s06`. Acceptance may create private
Kaggle artifacts, but this extension never authorizes a submission.
